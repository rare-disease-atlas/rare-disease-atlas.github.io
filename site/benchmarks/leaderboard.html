5 Hardest Translational Failure-Mode Traps in MyelofibrosisBench-v1.1

Standard biomedical QA benchmarks test textbook recall. MyelofibrosisBench-v1.1 specifically probes the 5 high-consequence reasoning traps where frontier models conflate superficially similar diseases, inverted signaling axes, or clinical endpoints:

# Failure-Mode Trap Naive LLM Hallucination Primary-Cited Ground Truth
01 SLE-AIMF Mimicking iMCD-TAFRO / Triple-Negative PMF Treats any MF-2/3 marrow fibrosis as irreversible clonal PMF -> recommends myeloablative HSCT or JAKi. JAK2/CALR/MPL-neg, HMR-neg, ANA+ marrow with polyclonal lymphoid aggregates is reversible AIMF (PMID:43061186); steroids/rituximab achieve 74–80% fibrosis resolution.
02 Hepcidin Polarity Inversion Prescribes hepcidin mimetic rusfertide (NCT05210790) to treat anemia of inflammation in MF/AIMF. Rusfertide restricts iron for PV erythrocytosis; anemic MF/AIMF has high IL-6 -> HAMP iron trapping requiring ACVR1/ALK2 suppression (momelotinib NCT04173494, PMID:42980647).
03 JH1 Hinge Cytopenia & Type I Y1007/Y1008 Persistence Assumes Type I JAK2 inhibitors fail due to secondary gatekeeper mutations or can be dose-escalated to clear clones. JH1 is 100% identical in WT vs V617F (PDB:3KRR), causing EPO/TPO cytopenias and Type I Y1007/Y1008 heterodimer persistence; requires JH2 allostery (PDB:4FVQ, INCB160058 NCT06313593) or Type II DFG-out (AJ1-11095 NCT06343805).
04 Phase 3 SVR35 vs. TSS50 / OS Dissociation Assumes doubling Week-24 SVR35 guarantees FDA approval or that OS is an easy Phase 3 salvage endpoint. MANIFEST-2 (NCT04603495), TRANSFORM-1 (NCT04472598), and SENTRY (NCT04562389) hit SVR35 yet missed TSS50; IMpactMF (NCT04576156) halted for OS futility (Oct 2026) -> drives FDA RDEA composite surrogates.
05 Intracellular JAK2 Modality & Pediatric PRV Confusion Proposes surface mAbs for intracellular JAK2 V617F or assumes adult MF qualifies for a $100M+ Rare Pediatric PRV. Surface mAbs work for extracellular mutCALR (INCA033989 NCT06034002), whereas intracellular JAK2 V617F needs JH2 binders/PROTACs (PDB:8BAK/8EX2); adult MF gets ODD ($4.68M PDUFA waiver), not a Pediatric PRV (unlike pediatric TBD ORPHA:1775).

Section 05 // 4-Tab 1-Command Quickstart (HF Datasets · lm-eval · Inspect AI · HTTP Grader)

Evaluate & Submit Your Agent Score

Run MyelofibrosisBench-v1.1 in your preferred evaluation stack or grade predictions with zero local installation via POST https://api.rare-disease-atlas.workers.dev/api/grade-benchmark:

Load the 50-item test split and 5-item dev calibration split directly from Hugging Face (CC-BY-4.0):

python3 -c 'from datasets import load_dataset; ds = load_dataset("rare-disease-atlas/MyelofibrosisBench"); print(ds); print(ds["test"][0]["id"], ds["test"][0]["category"])'

Clone the official harness (rare-disease-atlas/myelofibrosis-bench) and run with EleutherAI lm-evaluation-harness:

git clone https://github.com/rare-disease-atlas/myelofibrosis-bench.git && lm_eval --model hf --model_args pretrained=<your-model-id> --include_path ./myelofibrosis-bench/lm_eval_task --tasks myelofibrosis_bench

Run the native UK AISI inspect_ai task with automatic choice + mechanistic-reasoning scoring:

git clone https://github.com/rare-disease-atlas/myelofibrosis-bench.git && inspect eval myelofibrosis-bench/inspect_task.py --model openai/gpt-4o

Fetch ungraded questions via GET /api/grade-benchmark and submit predictions for instant deterministic grading + optional anonymous leaderboard publishing via POST /api/grade-benchmark:

curl -s https://api.rare-disease-atlas.workers.dev/api/grade-benchmark > questions.json
curl -s -X POST https://api.rare-disease-atlas.workers.dev/api/grade-benchmark \
  -H "Content-Type: application/json" \
  -d '{"model_name":"<your-model>","submit_to_leaderboard":true,"predictions":[{"id":"mf-bench-001","choice":"B","reasoning":"AIMF polyclonal lymphoid aggregates steroid rituximab 74-80% reversal PMID:43061186"}]}'
Transparent Privacy & Open-Science Notice: Leaderboard publishing (via POST /api/grade-benchmark with "submit_to_leaderboard": true or evaluate_agent.py --submit-anonymous-score) is 100% opt-in and stores only aggregate accuracy, per-category counts, reasoning-keyword coverage, and your chosen model_name string. Zero IP addresses, zero raw prompts, zero prediction text, and zero PII are logged or stored.
